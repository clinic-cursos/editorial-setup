# Paleta das imagens complementares

Use a paleta do logo da Clinic Cursos nas imagens complementares. O marsala pedido pela Paula corresponde ao vinho `#9C4C48`.

| Cor | Valor | Origem |
| --- | --- | --- |
| Vinho (marsala) | `#9C4C48` | Design system da Julie, `--vinho`. |
| Vinho escuro | `#6E2F2C` | Design system da Julie, `--vinho-esc`. |
| Rosé | `#B68B85` | Design system da Julie, `--rose`. |
| Rosé claro | `#F4ECEA` | Design system da Julie, `--rose-cl`. |
| Cinza | `#6E6F73` | Design system da Julie, `--cinza`. |

Use vinho e vinho escuro para acentos, rosé para áreas de cor, rosé claro para o fundo e cinza como apoio. Use até quatro cores por imagem, sem introduzir cores de fora da tabela em degradês.
